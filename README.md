# Aprende: sumas, restas y letras

App web (PWA) para niños de 4 y 5 años: sumas y restas, sílabas, lectura,
formar palabras, trazar letras, dictado y álbumes de premios.

- HTML, CSS y JavaScript sin dependencias.
- Sin seguimiento, sin cookies y sin conexiones externas: todo se guarda en el
  propio dispositivo.
- Funciona sin conexión (service worker) una vez abierta.

## Créditos de las voces

Las grabaciones de `audio/` se han generado con [Piper](https://github.com/OHF-Voice/piper1-gpl):

- Sumas y restas: voz «es_MX-claude-high» (licencia Apache 2.0).
- Lectura y premios: voz «es_ES-sharvard-medium», entrenada con el corpus
  Sharvard (Universidad de Edimburgo, https://datashare.ed.ac.uk/handle/10283/574),
  licencia Creative Commons BY 3.0.

Ver `audio/LEEME.txt`.
